# How to add `deploy/home/start.sh` to the chat

1. **View the file contents** in your terminal:
   ```bash
   cat deploy/home/start.sh
   ```
   (Run from the root of your git repository)

2. **Copy the output** (including all lines, whitespace, comments).

3. **Paste the copied content** into a new chat message, making sure it is **not** inside a code fence.

4. Send the message. I will then be able to see the file and answer your question about what the script does.

> **Alternative:** you can also add the file directly by sending its **full contents** between triple backticks with a bash language tag:
> ```bash
> # paste the whole script here
> ```

After you add the file, I will describe its purpose.
